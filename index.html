Pillar 02 · 生产力

合规判断工具（求职三件套）

开源许可证合规、隐私政策体检、代币监管定性 —— 每个都带「法律判断内核 + 条文级可解释证据」，能进流水线当门禁，而不只是 demo。

生产力型合规三件套

三个独立开源仓库，均为零依赖 Python CLI、含 Markdown（法律）+ JSON（工程）双报告与双重免责。点链接直达 GitHub。

oss-license-checker

开源许可证合规判定器 · 知产 / 开源法务
CI 绿 Python 3.8+ 32 tests MIT

解析依赖与 LICENSE，逐条比对兼容矩阵，输出「法律判断内核 + 条文级证据」，并导出 CycloneDX SBOM（对应 EO 14028 / 欧盟 CRA 合规诉求）。

  • 四态兼容判定：compatible / incompatible / one-way / conditional，争议标 disputed
  • Apache-2.0 → MIT 等真实兼容关系，未收录默认 unknown（不静默放行）
  • --fail-on {high,medium,low} 非零退出码，可作流水线门禁
GitHub 仓库 ↗

privacy-policy-checker

隐私政策合规体检器 · AI / 数据合规法务
CI 绿 Python 3.8+ 19 tests MIT

对照 PIPL / GDPR / CSL / DSL 检查项库，逐条判定 satisfied / partial / missing / not_applicable，并下沉到有效风险（none / low / medium / high）。

  • 中文双语对齐关键词、否定语境检测，避免对纯境内 / 非敏感产品误报
  • CSL（网络安全法）/ DSL（数据安全法）检查项库已上线，opt-in 启用
  • --fail-on {high,medium,low} 非零退出码，可作流水线门禁
GitHub 仓库 ↗

token-classifier

代币监管定性器 · Web3 / 加密公司法务
CI 绿 Python 3.8+ 37 tests MIT

跨 HK SFC / SG MAS / US SEC / EU MiCA 四法域，对代币做证券 / 监管定性，输出 Howey 四要素逐条证据与 MiCA 分类结论。

  • Howey 四要素逐条四态判定 + 综合证券定性（含置信度）
  • MiCA 四类：security(MiFID II) / EMT / ART / utility，判定优先级安全>EMT>ART>utility
  • --fail-on {likely_security,possibly_security} 非零退出码，可作发行前门禁

工程与合规姿态

离线优先 · 零依赖

仅用 Python 标准库，CI 矩阵 3.8 / 3.11 / 3.12 全通过，无供应链引入风险。

条文级可解释

每条结论附带法条依据与证据片段，而非黑箱标签；事实库带 source_url 与核验日期台账。

CI 门禁就绪

三件套均支持 --fail-on 非零退出码，可直接作为公司流水线的合规卡点。

合规与诚实声明：本人系统研习并实践 GDPR 与欧盟数据保护框架（含 IAPP CIPP/E 知识体系），但未持有 CIPP/E 等国际隐私认证；作品集中任何相关表述均为「研习 / 熟悉」而非「持证」。从业时长统一表述为「六年法律实务经验」，不写作「执业六年」。全部仓库开源 MIT，未声称私有或需授权访问。
